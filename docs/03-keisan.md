# けいさんの道とちからだめし（算数練習アプリからの移植）

作成日: 2026-11-21

算数「けいさん」は、算数練習アプリ（Space 試作。元のファイルは `src/learn/keisan/__original__/sansu-renshu.html` に写してある）と **同じもの** にする（ユーザーの決定）。ここに書いてあることを変えるときは、先にユーザーに確認する。

## ファイル

| ファイル | 中身 |
|---|---|
| `src/learn/keisan/generators.ts` | 問題の作り方（全ジェネレータ） |
| `src/learn/keisan/stages.ts` | 47ステージ（id・名前・テーマ・例・色・まとめ・筆算）。名前は13件だけ元から変えた。例は s47 だけ変えた。テーマは内部のメタ情報で、カードには出さない |
| `src/learn/keisan/session.ts` | 10問セット、星とクリア、記録の更新、どこまで遊べるか、入力の決まり、答えたあとの待ち時間 |
| `src/learn/keisan/ladder.ts` | ちからだめし（純粋関数。状態を受け取り、新しい状態と「次に何をするか」を返す） |
| `src/learn/keisan/keisan.test.ts` | 性質テスト（ステージごとに3000問作って答え・条件・4けた以内を確かめる、10問の重複） |
| `src/learn/keisan/keisan.original.test.ts` | 元の JS を Node（vm）で動かして照合するテスト |

乱数は `Rng`（`() => number`、0以上1未満）を引数で渡す。元の `Math.random()` を呼ぶ順番と同じ順番で使うので、同じ乱数の並びなら元と同じ問題が出る（照合テストで確かめている）。

## 問題の決まり

- 問題文は「数 演算子 数」。演算子は全角の `＋`（U+FF0B）・`−`（U+2212）・`×`・`÷`、前後に半角スペース。
- 数の範囲・くり上がりのパターン・条件に合うまで作り直す回数・あきらめたときの固定の問題は、元のまま。
- 10問のセットは、問題文の文字列で重複をはぶく（300回作ってもそろわなければ、重複を許して埋める）。
  - 九九の1つの段（s30〜s38）は問題が9通りしかないので、元の実装でも毎回1問かぶる。
- s6（ひき算 くり下がり）は、元の実装のまま 19 − 10 が出ることがある（`rnd(10, 9)` が 10 を返すため）。
- 答えの入力は4けたまで。答えは最大 8991（999 × 9）。

## 1回のステージ

- 10問。8問以上でクリア。星は 8問→★1、9問→★2、10問→★3。
- 記録: `cleared`（一度クリアしたら残る）、`stars`・`bestScore`（ベスト）、`bestTime`（秒。クリアできなかった回でも更新）。
- 「まえより はやい！」は、クリアして、前のベストより速く、筆算ステージ（`paper`: s25〜s28・s42）でないときだけ。
- 経過時間には答えたあとの待ちもふくむ。待ちは正解 500ms・不正解 1100ms（動きを減らす設定では 250ms・500ms）。
- `playableThrough`: ここまでは警告なしで遊べる（1〜48、48 はぜんぶクリア）。先のステージも警告つきで挑戦でき、クリアすると `stage.num + 1` まで解放（下がらない）。「つづきから」は `playableThrough` のステージ。

## ちからだめし（階段方式）

- 系統順: たし算（くふう含む）→ ひき算 → かけ算 → わり算。各系統は一番易しい段から登る。
  - たし算: 1, 3, 5, 8, 9, 11, 12, 14, 16, 18, 20, 23, 25, 27
  - ひき算: 2, 4, 6, 10, 13, 17, 19, 21, 22, 26, 28
  - かけ算: 30〜42
  - わり算: 44, 45
- 1段は2問。2問とも正解で合格、1問正解なら3問目を出して3問中2問で合格。
- 全問正解（3問目なし）の合格が2回続いたら、次は2段先へ。2段先で落ちたら、飛ばした1段だけを試して系統を終える。歩幅1段で落ちたら系統を終える。
- 系統を終えるとき、合格した段があれば締めの1問（最後に合格した段から。まちがえたら1段下からもう1問）。締めの問題は測定に入れない。
- まとめ（7, 15, 24, 29, 43, 47）と s46 は測らない。スタート地点の計算では「それより前が全部できていれば通りぬける」。
- 系統が終わるたびに仮のスタート地点（まだ測っていない系統はできるとみなす）を出し、そこより先から始まる系統は測らずに打ち切る。
- 全体で60問まで（ブロックが終わったときに判定し、そのブロックの結果を入れてから終える）。締めの問題は数えない。
- 系統の切れ目（休けい）でやめられる。途中の記録（`TestProgress`: able・asked・completedSystems・tentativeS・nextSys・ladderVersion）を保存し、次はその系統から。直前の問題文は引きつがない。
- 終わったら `playableThrough = max(今の値, スタート地点)`、`lastStage` はスタート地点のステージ（48 なら s47）、`testDone = true`、途中の記録は消す。
- 同じ問題文が続かないように、直前と同じなら20回まで作り直す。

## 元の実装と変えたところ

- 画面から切り離した（DOM・効果音・保存は呼ばない）。ちからだめしの状態は JSON にできる形（`able` などはオブジェクトではなく数の配列）。
- 乱数を引数で受け取る。
- s47（まとめ⑥）の例を `7 × 6 / 45 ＋ 38` から `56 ÷ 8 / 478 ＋ 586` に変えた。元は s43 と同じ例だったので、わり算と3けたが入った「全部」らしい例にした。出題（gMatome6）は変えていない。
- 旧形式の記録の移行（`OLD_TO_NEW`・`V21_TO_V28` など）は持ってこない（記録は新形式で始める決定）。
