### 問題の決まり

- 大小: 「どっちが おおきい？」の2択。ちがう数どうし。もう一方は近い数（けたの入れかえ・1けただけ変える・少しずらす）。単元5は ときどき 4けた と 5けた（9876 と 10002 のような）。しょうすうは 0.1〜4.9 と その近く（整数ちょうどは出さない）。
- 順番: 1ずつ ふえる4つの数（1〜100）の1か所が空欄。
- 数直線: 目盛りは 10・100・1000 きざみ。矢印は目盛りか、目盛りのまん中（5・50・500 きざみ。0 と はしは出さない）。モックの図に、まん中の短い目盛りだけ足した（まん中の数を読めるように）。
- 位取り入門: 2けた（一の位は1〜9）。「10が □こ」か「1が □こ」の どちらか。
- 分解: 3〜9 を 2つに（丸の絵の色つきが はじめの数）。合成: 和は10まで。10の分解: 1〜9。
- 位取り（1000まで）: 3けた。100・10・1 のどれか1か所が空欄。
- 言葉から数字: 101〜999 の読み（「さんびゃく じゅう ご」「ろっぴゃく はち」）。くらいごとに半角スペースで区切る。
- はんぶん・4とうぶん: ぬる場所の始まりは ばらばら。はんぶんでない円は 3分の1・3分の2・4分の1・4分の3・全部 から2つ。4分の1でない長方形は 2分の1・4分の2・3分の1・4分の3・全部 から2つ。2択の並びは いつも はんぶん → 4分の1。
- 位取り（万の位など）: 4けたか5けた。一・十・百・千・万 のうち、ある位を1つ聞く。
- 10倍: 10〜9999 の10倍。10分の1: 100〜99990（10の倍数）の10分の1。
- 分数の読み取り: 分母2〜8、分子は分母より小さい。上の欄が分子、下の欄が分母（「うえが ぶんし、したが ぶんぼ」と出す）。
- 分数の大小: 分母3〜10、分子は分母より小さい ちがう数。
- 分数の計算: 分母3〜10、和は1まで（分子の和 ≦ 分母）。
- 0.1の仕組み: 「0.1が □こで 0.7」。1〜19こ（1.9まで）。
- 小数の計算: 半分は 1より小さい数どうし（0.6 ＋ 0.3）。整数ちょうどの数は式に出さない。ひき算の答えは0より大きい。演算子は全角の `＋`・`−`。
- 答えは6けたまで（小数点は数えない）。

## 1回の単元

- 10問。単元のタイプを混ぜる: どのタイプも1回は出し、数はなるべく同じに（10問 ÷ タイプ数、あまりは ばらばらのタイプに1つずつ）。同じタイプは続けない。
- 中身が同じ問題は30回まで作り直す。単元4は問題の種類が少ないので、かぶることがある。
- 8問以上でクリア。星は 8問→★1、9問→★2、10問→★3（けいさんと同じ `judgeScore`）。
- 記録は `units[単元 id]` に星のベストとクリアだけ（`recordUnitResult`）。時間は残さない。結果画面で Worker へ送る。
- 道: まだクリアしていない最初の単元が「いま ここ」。そこまでは警告なし、先の単元は警告つきで選べる（ひらがなと同じ）。

## 画面（モックで承認された形式）

- 数字入力: キーパッドを画面の下に いつも出す（UI統一の方針、2026-11-23）。見出し行（すうじ／とじる）はない。問題が出たら はじめの欄に入力できる状態になり、欄のタップは「入力する欄の切り替え」だけに使う。「けってい」はパッドの中。判定のあともパッドは出したまま（次の問題が選択式なら消える）。
  - 欄が2つ（分数の読み取り）のときは、全部の欄が うまってから判定する。空の欄が残っていれば「けってい」で そこへ移る。
  - 小数点キー「.」は しょうすうの計算問題のときだけ出す。
  - 問題の部分は パッドを除いた のこりの高さに おさめる。図は高さの上限を `--kz-room`（のこりの高さ）から決めて縮める。分数の読み取りの円は 140px まで（最小 96px）。高さが 900px 以下で 幅のある画面（タブレットの横向きなど）では、円と 分数の欄を 横にならべ、マスコットを 56px にする。
  - 高さが足りない画面で まちがえたときは、「こたえは …」が見えるところまで 問題の部分を スクロールする。
- タップ選択: 選択肢をタップしたら すぐ判定。キーパッドは出さない。
- 正誤（けいさんと同じ）: ○×のマーク・マスコット・効果音・コンボ・紙吹雪。まちがえたら正解を少し見せて次へ（入力は「こたえは …」、選択は正しい選択肢に色）。待ちは正解 500ms・不正解 1100ms（動きを減らす設定では 250ms・500ms）。
- 結果: 星・せいかいの数・「つぎへ」（クリアしたとき）・「もういちど」・「みちへ もどる」。

## モックと変えたところ

- モックは まちがえたら やり直す形だったが、アプリでは けいさんと同じく「正解を少し見せて次へ」にした（回答フローは決定済みのため）。
- 数直線に、目盛りのまん中の短い目盛りを足した。両はしの数は はみ出さないよう、まん中ぞろえにした。
- 分数の欄の説明を「上の欄が 分子（ぶんし）、下の欄が 分母（ぶんぼ）」から「うえが ぶんし、したが ぶんぼ」にした（子ども向けの文言は ひらがな中心）。
- キーパッドは モックでは 欄をタップしたときだけ開いたが、UI統一の方針で 数字入力の問題では いつも出すようにした（2026-11-23）。
- 色は このアプリの色（さんすうの色 `#0891b2` と、入力欄・ボタンは けいさんと同じ色）。
