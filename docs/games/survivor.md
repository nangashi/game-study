# サバイバー（`survivor`）

共通の決まりは [../03-rewards-and-games.md](../03-rewards-and-games.md)、ゲームデザインの共通の考え方は [../05-game-design.md](../05-game-design.md)、画像の作り方は [../02-asset-generation.md](../02-asset-generation.md)。

## ひとことで

Vampire Survivors（ダダサバ）風。まわりから来る敵を自動で攻撃しながら、4分生き残るか、3分で来るボスをたおせばクリア。3つのせかい × 5ステージ。特徴の違う武器を3つまで持ち、育てて進化させる。

子どもに見せる説明（`GameDef.desc`）: 「てきを たおして いきのころう」

# デザイン

## ねらい

| | |
|---|---|
| だれに | 年長〜小学校低学年。ダダサバイバーが好きな子。字が読めなくても遊べること |
| どんな気持ちにさせたいか | 弱いところから始まり、最後は画面いっぱいの敵をなぎ倒す「強くなった！」気持ち。何度も遊んで、せかいを進み、図鑑を埋めていく楽しさ |
| 1回の長さ | 4分（共通の決まりは3〜7分） |
| 勉強とのつながり | 勉強でもらうコインで「つよくする」を買うと、先のステージに進める・選べる武器が増える。ゲームの中では勉強させない |

## 好まれると考えているポイント

「なぜ子どもが遊び続けるか」の仮説。根拠と、確かめたかどうかを書く。

| ポイント | 根拠 | このゲームでの形 | 確かめたか |
|---|---|---|---|
| 操作が「動くだけ」 | Vampire Survivors の分析: 入力を移動だけにして、判断を「どこに立つか」に集中させている | 画面のどこを触ってもスティック。攻撃は自動 | 以前からの形。子どもは遊べている |
| 数秒ごとに良いことが起きる | 同上: ジェム・レベルアップ・宝箱がひっきりなしに来るので、待つ時間がない | ジェム（続けて拾うと音が上がる）・アイテム・宝箱・100体ごとの大きな文字 | bot のみ |
| 最後は画面を埋めつくす敵をなぎ倒す | 同上: 「弱い → 圧倒的に強い」の弧がパワーの気持ちよさを生む | 敵をたくさん・弱く出す。1回で1,000〜2,000体たおせる | bot のみ |
| 進化は「しんか！」の瞬間 | Vampire Survivors: 進化がいちばん大きな強くなる瞬間。組み合わせの発見が長く遊ぶ理由になる | MAX + 宝箱で進化。組み合わせの条件は年長さんには難しいので使わない | bot のみ |
| 選ぶことで戦い方が変わる | ユーザーの指摘「プレイヤー側のランダム要素がなくて同じ動きしかしない」。Vampire Survivors も武器の枠数を限っている | 武器7つに特徴。持てるのは3つまで | 未 |
| 武器ごとに得意な敵・場面がある | ユーザーの指摘「ブーメランが強すぎ・どかーんが微妙・どかーんとほしがかぶる・かみなりが弱い」「どの敵・どの状況に強いかの差で使い分けたい」 | 「近いほど強い（危ないぶんのごほうび）・たくさんに当たるほど1発は弱い」で7つの役を分ける（下の「武器の役」） | 未 |
| 敵ごとに違う危なさ | ユーザーの指摘「敵キャラそれぞれの特徴がほしい」 | 15体すべて違う特徴。危ない攻撃には必ず合図 | 未 |
| 危なくないと作業になる | ユーザーの指摘「ステージ1の敵が弱すぎて危なくなる要素もなく作業チック」 | ステージ1から弾を撃つ敵。ただし数に上限（多すぎると「近づけない・たおせない」になる。版4） | 未 |
| 章（せかい）ごとに景色と敵が変わる | Survivor.io: 章ごとに敵とボスが変わり、次に進む目標になる | 3つのせかい。地面・敵・ボスが変わる | 未 |
| 集める・埋める | Vampire Survivors: 隠し要素の発見が長く遊ぶ理由（GDC でも言及） | ★（45個）、ずかん（敵18・進化7） | 未 |
| 自分で選んで買う | Brotato: 波の合間のショップで組み合わせを作るのが核 | ⭐メダルでおみせ（1:30・2:50）。値段は30まで | 未 |
| 止まりすぎない | ユーザーの指摘「レベルアップが頻繁すぎてテンポが悪い」 | 1回15〜20回 | bot のみ |
| だらだら続かない | ユーザーの指摘「ボーナスが長すぎてダレる」 | ボスをたおしたらすぐクリア | — |

## 仕組みと意図

| 仕組み | 意図 | ためして、やめたこと |
|---|---|---|
| 3つのせかい × 5ステージ、5ステージめはボス | 見た目が変わると「先に進んだ」とわかる。勉強で進む目標になる | ステージなし（1回きり） |
| 時間で起きるイベント（群れ・囲まれる・敵3倍・強い敵・おみせ・ボス） | 1回の中に山と谷を作る。「次は何が来る？」で飽きさせない | 時間で数が増えるだけ |
| 敵の役（群れ・速い・突進・遠くから・硬い）+ 敵ごとの特徴 | 逃げ方を1つにしない。役は共通なので、せかいが変わっても覚えることは増えない | 全部まっすぐ追いかけるだけ |
| 危ない攻撃には必ず合図（赤い輪・赤くなって震える・ふくらむ・敵の弾は赤） | 年長さんでも見てよけられる。理不尽にやられない | — |
| 武器7つ、特徴つき、持てるのは3つ | 全部持てると選ぶ意味がない。何を持つかで戦い方が決まる | 武器5つを全部持てる |
| 武器の強さは「届く距離」と「当たる数」で決める | 近い武器は危ないぶん強く、たくさんに当たる武器は1発を弱くする。どれか1つが何でもできると選ぶ意味がなくなる | ブーメラン（つらぬく・遠い・自動でねらう・何度も当たる）が何でもできて強すぎた |
| どかーん（まわりの爆発）→ ばくだん（遠くのかたまりに投げる） | まわるほしと役がかぶっていた。遠い＋範囲の武器がなく、離れて撃つ敵をたおす手が少なかった | どかーん: 自分のまわりを吹きとばす（まわるほしとかぶる・吹きとばすので次が当たらない） |
| かみなりは「つながる」 | レベルで連鎖が増えるのが目に見えて強くなる。しびれて突進が止まる | 画面のどこかにランダムに落ちる（自分を守れない・安定しない） |
| 弾を撃つ敵は、1体ずつ・上限つき・近づけば届く距離まで | 撃つ敵が遠くにたまって弾だらけになり「近づけない・たおせない」だった | まとめて出す・230pxより近づくと逃げる |
| 武器の種類は「つよくする」で解放、ゲームの中では Lv1 から | 勉強のごほうびが「強くなる」だけでなく「選べる武器が増える」になる | 最初の武器を+1つ持てる解放（強さが上がるだけで選ぶ楽しさにならない） |
| 進化は MAX + 宝箱 | 年長さんでもわかる。強い敵 → 宝箱 →「しんか！」がいちばんのごほうびの瞬間 | 組み合わせ条件（Vampire Survivors 式） |
| ⭐メダルとおみせ | 運（レベルアップ）だけでなく、自分で選んで買う。値段を比べるのは算数にもなる（問題は出さない） | — |
| 永続強化の値段が上がっていく | 勉強1回で1つ買えると、すぐ買い占められる | 25コインで一定 |
| 4分でクリア、ボスをたおせば早くクリア | ボスをたおす目標と、たおせなくてもクリアできる安心を両方 | ボスをたおすとボーナスタイム（最長7分）→ だれた |
| ★（クリア・ボス・ハート半分）とずかん | 強さに関係なく、集める楽しさで続ける理由を作る | — |
| レベルアップのクイズをやめた | 勉強とゲームを分ける（共通の決まり 8.） | 正解するとスキル2段階 |

## バランス

### 考え方: 3つの軸

| 軸 | 何で決めるか | ねらい |
|---|---|---|
| ステージ間 | 推奨コイン（共通の決まり 5.）→ 推奨強化レベル → 敵の体力・速さ | 1ステージ進むのに「クリア + 勉強2回」。推奨より少ない強化では負ける |
| 1回の中（時間） | 敵の体力 `× (1 + t/150)`、出てくる間隔、イベント | だんだん危なくなり、ボスで山場 |
| 1回の中（プレイヤーの成長） | 経験値の曲線、⭐メダル、宝箱 | 15〜20回のレベルアップで、3つの武器のうち1〜2つを進化できる |

### 主な数値

| 数値 | いまの値 | 場所 |
|---|---|---|
| 推奨コイン | `80 × (n − 3)` | `src/state/economy.ts` |
| 強化の値段 | 数値: `40 + 20 × レベル`（全部で5200）。武器の解放 120〜180、わく 300、えらびなおし 80〜160 | `upgrades.ts` |
| 推奨強化レベル | 推奨コインで買える数値の強化の数（ステージ4で2、10で10、15で14） | `recommendedLevel` |
| 敵の体力 | `1 + 0.07 × 推奨強化レベル`、時間で `× (1 + t/150)` | `stages.ts` / `BattleScene.ts` |
| 敵の速さ | `1 + 0.01 × 推奨強化レベル` | `stages.ts` |
| 敵の多さ | `density = 0.7 + 0.1 × (せかいの中のステージ番号、3まで)`、同時に出ている数の上限 `60 + 10 × ステージ`（160まで）。スライムなどのかたまりは `3 + t/60` 匹 | `stages.ts` / `BattleScene.ts` |
| 弾を撃つ敵 | いつも1体ずつ出す。同時に `2 + せかいの中のステージ番号 + せかい`（ステージ1で3、15で9）まで。撃つ間隔 4.2〜6秒。170pxより近いと下がる | `stages.ts` / `BattleScene.ts` |
| 経験値 | 次のレベルまで `5 + 2L + 0.7L²` | `BattleScene.ts` |
| 自分 | ハート `5 + たいりょく`、こうげき `1 + 0.25 × こうげき`、やられたあと1.5秒無敵 | `BattleScene.ts` |
| ⭐メダル | 弱い敵 2.5〜3%、突進・遠く 8%、硬い 2枚、強い敵 8枚。おみせは30まで | `BattleScene.ts` / `skills.ts` |
| やさしい設定 | ハート +3、敵の数 0.6倍・速さ 0.85倍、ボスの体力半分 | `BattleScene.ts` |

### 調整の進め方

1. 数値を変えたら `npm test`（ステージ・スキル・おみせのテスト）
2. `node scripts/playtest-survivor.mjs` で bot に遊ばせる。見るのは次の3つ
   - 推奨強化レベルでクリアできるか（`--stage=n`）
   - 強化が足りないと負けるか（`--stage=8 --up=0` など）
   - ハート・レベル・敵の数が時間でどう動くか（10秒ごとのログとスクリーンショット）
3. 同じ条件でも結果がばらつくので、1つの条件を2回以上見る
4. 最後は子どもに遊んでもらって決める（bot は逃げ続けるのがうまく、子どもとは違う）

```bash
node scripts/playtest-survivor.mjs --stage=5                  # 推奨強化レベル（数値の強化だけ）
node scripts/playtest-survivor.mjs --stage=10 --weapons=all   # 武器を全部解放して
node scripts/playtest-survivor.mjs --stage=8 --up=0           # 強化なしで
node scripts/playtest-survivor.mjs --stage=1 --only=sword --bot=brave  # 武器1つだけで、敵に近づいて戦う bot
```

- `--only=<武器>`: その武器1つだけで遊ぶ（武器どうしの強さを比べる）。最後に武器ごとの与えたダメージ（`dealt`）を出す
- `--bot=brave`: 敵に近づいて戦う。ふつうの bot（smart）は逃げ続けるので、近い武器（つるぎ・まわるほし）はほとんど当たらない

準備: `npm i --no-save playwright && npx playwright install chromium-headless-shell`。

|---|---|---|
| 1 | ステージ・せかい・敵の役・イベント・進化・★・ずかんを足した。敵の体力 `0.125 × R`（ひっぱりアタックと同じ） | 「単調・積み上げがない・変化がない・爽快さがない」。ステージ10・15で序盤に敵がたまりすぎて負けた → `0.085` |

| 5 | ばくだんの届く距離 150〜480px → 120〜360px。分かれたスライムの子は0.25秒こうげきがきかない。ながれぼし 2 → 1.8、0.45 → 0.6秒ごと、つらぬく 3 → 2体 | ユーザーの指摘「ばくだんが分かれる前のスライムを子までまとめて1発でたおすのはやりすぎ・射程が長い」「ながれぼしが強い」。原因: 爆発の中でスライムが分かれると、子がすぐ同じ爆発に当たっていた（敵の一覧に足された子まで見ていた）。bot（武器1つ・ステージ1・brave）: ばくだん 4,595 → 1,385（2:42で負け。4分にならすと約2,000で、ほかの武器と同じくらい）、まほうだま 4,289 → 2,246（クリア）。ステージ6（推奨）は2回中1回クリア（版4は3回中2回） |

### わかっている問題

- bot は逃げ続けるのがうまく、強化なしで逃げきることがある（子どもはもっとぶつかるはず）
- 武器の強さはステージで変わる。敵がやわらかいステージ1では範囲（ばくだん）、硬いステージ12では何度も当たるブーメランが強く出た
- つるぎ・まわるほしは、ふつうの bot（逃げ続ける）ではほとんど当たらない。近づいて戦う子どもで確かめる
- ながれぼし（まほうだまの進化）が強かった → 版5で弱くした。子どもが遊んで確かめる
- おかしのくにの後半（14・15）は推奨強化レベルだと厳しめ
- 結果のばらつきが大きい（出てくる武器の運・bot の動き）。子どもが遊んだ結果で合わせる

# 仕様

## 世界観と見た目

- 舞台: せかいごとに変わる（くさはら → ゆきやま → おかしのくに）。地面と敵がせかいごとに違う。ゆきやま・おかしのくには地面を少し暗くして、白っぽい敵を見やすくしている
- 主人公: 子どものアバター（土台の画像 `art/common` の `hero_*`）
- 色: むらさき（`--game-accent: #7c3aed`）、タイトルの字は黄色

## 1回の遊び方

- 4:00 生き残ればクリア。3:00 に来るボスをたおすとその場でクリア。ハートが0で負け（`stages.ts` の `MAIN_SECONDS` / `BOSS_AT`）
- 操作: 画面のどこを触っても、そこを中心にバーチャルスティックで動く。攻撃は自動
- 1回の中の流れ（`stageSpec().events`）:

| 時間 | できごと |
|---|---|
| 0:20 / 1:20 / 2:30 / 3:30 | アイテムが落ちる（ばくだん = 画面の敵が全部はじける、じしゃく = ジェムを全部すいよせる、おにく）。画面の外なら、はしに矢印 |
| 0:40 / 2:40 | 群れ: 速い敵が列になって画面を横切る |

## 敵

役（動き方の基本）はせかいによらず同じ。その上に敵ごとの特徴（`Trait`）があり、15体すべて違う（`WORLDS[].traits`。ずかんにも出す）。

| 役 | 基本 | くさはら | ゆきやま | おかしのくに |

| swarm（弱い・かたまり） | 追いかける | スライム: たおすと2匹に分かれる（分かれた子は0.25秒こうげきがきかない。範囲の1発で分かれる前と子をまとめてたおさない） | ゆきだるま: ときどき雪玉を投げる | グミ: ぴょんぴょん跳ねて近づく |

## ステージ

- 15ステージ（`SURVIVOR_STAGES`）= 3つのせかい × 5。5ステージめはせかいのボス（王冠）
- タイトル画面で、クリアしたステージと次のステージを選べる（遊び直しもできる）
- ★（ステージごとに3つ、いちばん良かったときを残す）: クリア / ボスをたおした / ハートが半分より多く残った
