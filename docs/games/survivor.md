# サバイバー（`survivor`）

共通の決まりは [../03-rewards-and-games.md](../03-rewards-and-games.md)、画像の作り方は [../02-asset-generation.md](../02-asset-generation.md)。

## ひとことで

ダダサバ（Vampire Survivors）風。まわりから来る敵をオートでこうげきしながら、3分いきのこればクリア。
説明: 「てきを たおして いきのころう」

## 世界観と見た目

- 舞台: ファンタジーの草原（夕やけ）
- 主人公: **子どものアバター**（土台の画像 `art/common` の `hero_*`）をそのまま使う
- 色: むらさき（`--game-accent: #7c3aed`）、タイトルの字は黄色

## 1回の遊び方

- 3分（`RUN_SECONDS`、`src/games/survivor/main.ts`）。いきのこればクリア、ハートが0で負け
- 操作: 画面のどこをさわっても、そこを中心にバーチャルスティックで動く。こうげきは自動
- やさしい設定: ハート +3、敵が少なく遅い

## ステージ

- まだない（`stages: 1`）。いつもステージ1として記録する
- 共通の決まり 5.（ステージごとに推奨強化レベルへそろえる）は、ステージを作るときに対応する

## 2つの成長

| | 中身 |
|---|---|
| ラン内の成長 | レベルアップで3つからえらぶスキル（まほうだま・まわるほし・どかーん・はやあし・げんき・すいよせ。`skills.ts`） |
| ずっと残る強化 | たいりょく・こうげき・すばやさ・じしゃく |

- レベルアップのときにクイズがあり、正解するとスキルが2レベル上がる（スーパー）。共通の決まり 8. より前に作ったもの。残すかは改善のときに決める

## 画面

- タイトル画面: 背景 `title_bg`、アバターが歩く、さいこう記録・クリア回数、あそぶ（🎟️1）・つよくする・もどる
- 遊ぶ画面: Phaser（`BattleScene.ts`）。右下に「やめる」
- 結果画面: 生きのこった秒数・たおした数・レベル・コイン

## 画像（`art/games/survivor/art.json`）

| 出力 | 中身 | 元の生成画像 |
|---|---|---|
| `enemies` | スライム・おばけ・コウモリ・キノコ・ゴーレム・ドラゴン（3x2、160px） | `enemies.png` |
| `icons` | まほうだま・まわるほし・ジェム・爆発・ハート・くつ・じしゃく・剣・星・時計・双剣・ハンマー（128px） | `common/icons1`・`common/icons2` から取り出して並べ直し |
| `ground` | 地面（敷きつめ、512px） | `ground.png` |
| `title_bg` | タイトル画面の背景（1600px） | `title_bg.png` |

## ファイル

| ファイル | 中身 |
|---|---|
| `index.ts` | `GameDef` |
| `main.ts` | タイトル画面・遊ぶ流れ・スキルえらび |
