# ひっぱりアタック（`hippari`）

共通の決まりは [../03-rewards-and-games.md](../03-rewards-and-games.md)、画像の作り方は [../02-asset-generation.md](../02-asset-generation.md)。

## ひとことで

モンスト風。まんまるの どうぶつを ひっぱって はなし、はねかえりながら おもちゃの敵に ぶつけるターン制のゲーム。
説明: 「ひっぱって はなして てきに ぶつけよう」

## 世界観と見た目

- 舞台: おもちゃのくに。遊ぶ場所は、上から見たパステルのプレイマット
- 主人公: **このゲームだけのキャラ**（まんまる どうぶつ6ひき: パンダ・ひよこ・ペンギン・ハムスター・こぶた・こぐま）。子どものアバターとは別で、タイトル画面でえらぶ。見た目だけで、どれでも強さは同じ（えらんだキャラは `platform.saveData` に保存）
- 敵: ねじまきロボ・こま・おもちゃのきょうりゅう・くまのぬいぐるみ・つみきゴーレム、ボスはロボのおうさま
- 色: オレンジ（`--game-accent: #f97316`）、タイトルの字は白にピンクのふち

## 1回の遊び方

- 1ステージは敵の「なみ」が2〜3つ。ぜんぶたおせばクリア、ハートが0で負け
- 自分の番: 画面のどこでもさわって、うしろにひっぱって はなす。ひっぱった長さで いきおいが決まる。点線でねらいが見える
- たまはかべ（マットのふち）と敵で はねかえり、だんだん止まる。当たるたびにダメージ
- 敵の番: たまが止まるたびに敵の数字（カウント）が1へり、0になった敵が とびかかってくる（ハートがへる）
- 1回の長さの目安: 2〜4分（まだ実際に遊んで確かめていない）
- 字が読めなくてもわかるように、はじめは「ひっぱる手」が動いて見せる
- やさしい設定: ハート +3、敵のカウント +1、ねらいの点線が長い

## ステージ

- 20ステージ（`HIPPARI_STAGES`）。タイトル画面で、クリアしたステージと次のステージをえらべる（遊び直しもできる）
- 5ステージごとにボス（ロボのおうさま）。4ステージから、さいごのなみに大きい敵
- 敵の並びはステージごとにいつも同じ（ステージ番号から乱数を作る）
- 敵の強さ: HP の倍率 `enemyPower(n) = 1 + 0.125 × recommendedLevel(n)`（こうげき強化を推奨レベルの半分ふったときと同じ）。こうげき力は `1 + floor(R/10)`。ステージ1〜3は数と種類だけで変える（`stages.ts`、テストあり）

## 2つの成長

| | 中身 |
|---|---|
| ラン内の成長 | なみをたおすたびに3つからえらぶスキル: ちから・つらぬき・ぶんしん・どかーん・かべパワー・げんき（`skills.ts`） |
| ずっと残る強化 | たいりょく（ハート +1）・こうげき（+25%）・いきおい（はやさ +6%）・かいふく（なみをたおすとハートがもどる） |

- クイズは出さない（共通の決まり 8.）

## 画面

- タイトル画面: 背景 `title_bg`、キャラえらび、ステージえらび（クリア=旗、ボス=王冠、まだ=かぎ）、あそぶ（🎟️1）・つよくする・もどる
- 遊ぶ画面: Phaser（`HippariScene.ts`）。720×1080 の縦長。横向きの画面では中央に表示する。右下に「やめる」
- 結果画面: なみ・さいこうヒット数・コイン。はじめてクリアしたら、つぎのステージをえらんだ状態でタイトルにもどる

## 決めたことと理由

| 決めたこと | 理由 |
|---|---|
| ターン制にする | 年長さんでも自分のペースで遊べる。ねらいを考える楽しさがある |
| キャラはアバターと別にし、見た目だけにする | ゲームの世界に合う見た目にしたい。強さに差をつけるとコインで遊び方が変わってしまう（共通の決まり 4.） |
| 敵の並びはステージごとに固定 | 同じステージをくり返すと上手になるのがわかる |

## あそびラボの試作（`sling`）で出た案

同じ「ひっぱりアタック」の試作があそびラボにあった（アクション寄り: カメラ固定の闘技場で、飛んでいる途中でも撃ち直せる）。正式なゲームにしたのでラボからは外した。そこで出た案のうち、使えそうなもの:

- 速いあいだは無敵にして、当たった敵を吹き飛ばす。吹き飛んだ敵がほかの敵に当たると連鎖する（コンボが伸びて気持ちいい）
- 当たったときのヒットストップと効果音（WebAudio で合成、`src/lab/common.ts` の `sfx`）
- 心配だったこと: 連打すればいつも無敵でいられる（→ このゲームはターン制にしたので起きない）。「引いた向きと逆に飛ぶ」が年長さんに伝わるか（→ ねらいの点線と、ひっぱる手の動きで見せている）

## まだのこと

- 子どもが推奨強化レベルでクリアできるか、実際に遊んで数字を合わせる（たまの速さ・止まり方・敵の HP）
- ボスだけの動き（2回こうげきなど）
- 効果音（ラボの `sfx` を使える）
