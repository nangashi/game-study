# ひっぱりアタック（`hippari`）

共通の決まりは [../03-rewards-and-games.md](../03-rewards-and-games.md)、ゲームデザインの共通の考え方は [../05-game-design.md](../05-game-design.md)、画像の作り方は [../02-asset-generation.md](../02-asset-generation.md)。

## ひとことで

モンスト風。まんまるの どうぶつを ひっぱって はなし、はねかえりながら おもちゃの敵に ぶつけるターン制のゲーム。
説明: 「ひっぱって はなして てきに ぶつけよう」

# デザイン

## ねらい

| | |
|---|---|
| だれに | 年長〜小学校低学年。反射神経より「考えてねらう」のが好きな子。サバイバーの速い動きが苦手な子の選択肢 |
| どんな気持ちにさせたいか | ねらいどおりに跳ね返って、たくさんの敵に当たったときの「やった！」。1回ひっぱるごとに結果が見える手ごたえ |
| 1回の長さ | 3〜7分（波2〜3つ）。まだ遊んで確かめていない |
| 勉強とのつながり | 勉強でもらうコインで「つよくする」を買うと、先のステージに進める。ゲームの中では勉強させない |

## 好まれると考えているポイント

| ポイント | 根拠 | このゲームでの形 | 確かめたか |
|---|---|---|---|
| ひっぱって離すだけ | モンスターストライク（国内で子どもにも遊ばれている）。スマホの引っぱり操作は直感的 | 画面のどこでもひっぱる。長さで勢い | 未 |
| 自分のペースで考えられる | ターン制は反射神経がいらない。年長さんでも置いていかれない | 敵はボールが止まってから動く | 未 |
| 跳ね返りで連鎖する | ビリヤード・ピンボールの「狙いが当たる」気持ちよさ | 壁と敵で跳ね返り、当たるたびにダメージ。「◯ヒット！」 | 未 |
| 見て、次を予想できる | 敵の頭の数字（あと何回で攻撃してくるか）が見える | 数字が0の敵を先にたおす、という考え方が生まれる | 未 |
| 同じステージで上達がわかる | 並びが毎回同じなら、前より少ない回数でクリアできる | 敵の並びはステージごとに固定 | 未 |
| かわいいキャラを選ぶ | 自分のキャラを持つと愛着がわく | まんまる動物6匹から選ぶ（見た目だけ） | 未 |
| 字が読めなくてもわかる | 年長さんは字を読まない | 最初は「ひっぱる手」が動いて見せる。ねらいの点線 | 未 |

## 仕組みと意図

| 仕組み | 意図 | ためして、やめたこと |
|---|---|---|
| ターン制 | 年長さんでも自分のペースで遊べる。ねらいを考える楽しさ | ラボの試作 `sling`（アクション寄り。飛んでいる途中でも撃ち直せる）→ 連打すれば無敵になれてしまう |
| ねらいの点線（やさしい設定では長い） | 「引いた向きと逆に飛ぶ」を見せる | — |
| 波をたおすごとにスキルを3つから選ぶ | 1回の中の成長。跳ね返り型（かべパワー）・数型（ぶんしん）・範囲型（どかーん）で戦い方が変わる | — |
| 敵の攻撃までのカウント | 何を先にたおすかを考えさせる。はじめは1つずつずらして、一度に攻撃されないようにする | — |
| 5ステージごとにボス、4ステージから大きい敵 | 進んだ実感と山場 | — |
| キャラは見た目だけ | 強さに差をつけない（選ぶ楽しさは見た目で出す） | — |

## バランス

### 考え方

| 軸 | 何で決めるか | ねらい |
|---|---|---|
| ステージ間 | 推奨コイン（共通の決まり 5.）→ 推奨強化レベル（1段階40コインで一定なので、1ステージに2段階）→ 敵の HP | 1ステージ進むのに「クリア + 勉強2回」 |
| 1回の中 | 波の数（2〜3）・敵の数・カウント | 最後の波ほど多く・大きく |
| プレイヤーの成長 | 波ごとのスキル | 最後の波で連鎖が伸びる |

### 主な数値

| 数値 | いまの値 | 場所 |
|---|---|---|
| 強化の値段 | 1段階 40コインで一定 | `upgrades.ts` |
| 敵の HP | `1 + 0.125 × 推奨強化レベル`（こうげき強化を推奨レベルの半分ふったときと同じ）。ステージ1〜3は数と種類だけで変える | `stages.ts` |
| 敵の攻撃力 | `1 + floor(推奨強化レベル / 10)` | `stages.ts` |
| 敵の数 | 1つの波に `min(2 + floor((n−1)/4) + 波の番号, 6)` | `stages.ts` |
| ボール | 最大の勢い 1900（いきおい強化で +6%）、摩擦は速いほど強い（目いっぱいで約4秒・画面2つぶん） | `HippariScene.ts` |
| ダメージ | こうげき × (1 + 0.25 × かべパワー × 壁に当たった回数)、分身は半分 | `HippariScene.ts` |
| 自分 | ハート `5 + たいりょく`、波をたおすと `かいふく / 2` 回復 | `HippariScene.ts` |
| やさしい設定 | ハート +3、敵のカウント +1、ねらいの点線が長い | `stages.ts` / `HippariScene.ts` |

### 調整の進め方・記録

- 数値を変えたら `npm test`（`stages.test.ts`: 敵の強さが推奨強化レベルにそろって足し算で上がるか）
- 自動プレイの bot はまだない。子どもに遊んでもらって、ボールの速さ・止まり方・敵の HP を合わせる

| 版 | 変えたこと | きっかけ・結果 |
|---|---|---|
| 1 | 20ステージ・波・スキル・強化（1段階25コイン） | ラボの `sling` を正式なゲームにした |
| 2 | 強化を1段階40コインに（推奨強化レベルは1ステージ2段階のまま） | 共通の決まり 5. を推奨コインにしたため。難しさは変わらない |

### わかっている問題

- 実際に遊んで確かめていない（1回の長さ・難しさ）

# 仕様

## 世界観と見た目

- 舞台: おもちゃのくに。遊ぶ場所は、上から見たパステルのプレイマット
- 主人公: **このゲームだけのキャラ**（まんまる どうぶつ6ひき: パンダ・ひよこ・ペンギン・ハムスター・こぶた・こぐま）。子どものアバターとは別で、タイトル画面でえらぶ。見た目だけで、どれでも強さは同じ（えらんだキャラは `platform.saveData` に保存）
- 敵: ねじまきロボ・こま・おもちゃのきょうりゅう・くまのぬいぐるみ・つみきゴーレム、ボスはロボのおうさま
- 色: オレンジ（`--game-accent: #f97316`）、タイトルの字は白にピンクのふち

## 1回の遊び方

- 1ステージは敵の「なみ」が2〜3つ。ぜんぶたおせばクリア、ハートが0で負け
- 自分の番: 画面のどこでもさわって、うしろにひっぱって はなす。ひっぱった長さで いきおいが決まる。点線でねらいが見える
- たまはかべ（マットのふち）と敵で はねかえり、だんだん止まる。当たるたびにダメージ
- 敵の番: たまが止まるたびに敵の数字（カウント）が1へり、0になった敵が とびかかってくる（ハートがへる）
- 1回の長さの目安: 3〜7分（まだ実際に遊んで確かめていない。短ければ なみを ふやす）
- 字が読めなくてもわかるように、はじめは「ひっぱる手」が動いて見せる
- やさしい設定: ハート +3、敵のカウント +1、ねらいの点線が長い

## ステージ

- 20ステージ（`HIPPARI_STAGES`）。タイトル画面で、クリアしたステージと次のステージをえらべる（遊び直しもできる）
- 5ステージごとにボス（ロボのおうさま）。4ステージから、さいごのなみに大きい敵
- 敵の並びはステージごとにいつも同じ（ステージ番号から乱数を作る）
- 敵の強さ: HP の倍率 `enemyPower(n) = 1 + 0.125 × recommendedLevel(n)`（こうげき強化を推奨レベルの半分ふったときと同じ）。強化は 1段階40コインで一定（`upgrades.ts`）なので、推奨強化レベルは 1ステージにつき2段階。こうげき力は `1 + floor(R/10)`。ステージ1〜3は数と種類だけで変える（`stages.ts`、テストあり）

## 2つの成長

| | 中身 |
|---|---|
| ラン内の成長 | なみをたおすたびに3つからえらぶスキル: ちから・つらぬき・ぶんしん・どかーん・かべパワー・げんき（`skills.ts`） |
| ずっと残る強化 | たいりょく（ハート +1）・こうげき（+25%）・いきおい（はやさ +6%）・かいふく（なみをたおすとハートがもどる） |

- クイズは出さない（共通の決まり 8.）

## 画面

- タイトル画面: 背景 `title_bg`、キャラえらび、ステージえらび（クリア=旗、ボス=王冠、まだ=かぎ）、あそぶ（🎟️1）・つよくする・もどる
- 遊ぶ画面: Phaser（`HippariScene.ts`）。720×1080 の縦長。横向きの画面では中央に表示する。右下に「やめる」
- 結果画面: なみ・さいこうヒット数・コイン。はじめてクリアしたら、つぎのステージをえらんだ状態でタイトルにもどる

## ほかに決めたこと

| 決めたこと | 理由 |
|---|---|
| キャラはアバターと別にし、見た目だけにする | ゲームの世界に合う見た目にしたい。共通の決まり 4. が変わり、永続強化で「解放」を使えるようになったので、キャラごとの わざを解放にするのは これからの候補 |
| 敵の並びはステージごとに固定 | 同じステージをくり返すと上手になるのがわかる |

## あそびラボの試作（`sling`）で出た案

同じ「ひっぱりアタック」の試作があそびラボにあった（アクション寄り: カメラ固定の闘技場で、飛んでいる途中でも撃ち直せる）。正式なゲームにしたのでラボからは外した。そこで出た案のうち、使えそうなもの:

- 速いあいだは無敵にして、当たった敵を吹き飛ばす。吹き飛んだ敵がほかの敵に当たると連鎖する（コンボが伸びて気持ちいい）
- 当たったときのヒットストップと効果音（WebAudio で合成、`src/lab/common.ts` の `sfx`）
- 心配だったこと: 連打すればいつも無敵でいられる（→ このゲームはターン制にしたので起きない）。「引いた向きと逆に飛ぶ」が年長さんに伝わるか（→ ねらいの点線と、ひっぱる手の動きで見せている）

## まだのこと

- 子どもが推奨強化レベルでクリアできるか、実際に遊んで数字を合わせる（たまの速さ・止まり方・敵の HP）
- ボスだけの動き（2回こうげきなど）
- 効果音（ラボの `sfx` を使える）
